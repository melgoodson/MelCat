Pre-Authorizing Amazon Order IDs

A step-by-step guide for Shopify administrators to upload authorized Amazon Order IDs, enabling seamless, instant customer reward activations.

✨ Admin Tool Fulfillment Funnel Version 1.2

Overview

When customers buy physical Snarky Pets packs (such as the Cat Tunnel Lite Pack or the Cat Cube Lite Pack) on Amazon, they receive a package insert prompting them to claim their digital bonus companion app entitlements.

To enable instant validation for these customers without manual claim review, you can pre-authorize (or "seed") their Amazon Order IDs directly into the MelCat Database. When the customer submits their matching Order ID on the storefront claim page, the system automatically validates and grants access.

Manually Pre-Authorizing Orders

Follow these steps to pre-authorize one or more Amazon Order IDs:

1

Navigate to the MelCat Dashboard

Log in to your Shopify Admin Portal. In the left-hand sidebar under Apps, click on MelCat Dash (or search for the MelCat Dashboard app).

2

Locate the Pre-Authorize Panel

Scroll down to the right side of the screen where you see the card labeled Pre-Authorize Amazon Orders.

3

Format & Paste the Order IDs

In the text field area, enter the Amazon Order IDs. You can enter multiple Order IDs at once by placing each ID on a new line.

ℹ️ Accepted Format

Amazon Order IDs must follow the standard 19-digit pattern (separated by hyphens):
XXX-XXXXXXX-XXXXXXX (e.g. 123-4567890-1234567)

4

Select the Product SKU

Use the dropdown menu directly below the text box to choose the product associated with these Order IDs:

  • Cat Tunnel (Lite Pack) (SKU: cat-tunnel)
  • Cat Cube (Lite Pack) (SKU: cat-cube)
5

Submit to Save

Click the orange ⚡ Authorise Orders button. The app will process each line and display a confirmation message indicating how many Order IDs were successfully saved/updated.

Reviewing & Approving Submitted Claims

If a customer submits an Amazon Order ID that was not pre-authorized, it will appear in the Submitted Amazon Claims table with a PENDING status.

6

Manual Review and Action

To manually review and handle these claims:

  1. Locate the Submitted Amazon Claims table in the middle of the dashboard.
  2. Review the Order ID, customer email, and submission date.
  3. Click Approve to instantly approve the claim, mark the order as claimed, and grant the digital entitlement.
  4. Click Reject if the order ID is invalid or cannot be verified.
⚠️ Important Security Note

An Order ID can only be claimed once. The system will prevent duplicate claims across different email addresses to protect digital products and assets.
